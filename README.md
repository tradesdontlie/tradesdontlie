## Open-source flagship

### [TradingView MCP](https://github.com/tradesdontlie/tradingview-mcp)

**6,700+ GitHub stars** · AI-assisted chart analysis and Pine Script development.

Connects Claude Code to a locally running TradingView Desktop session through the Model Context Protocol and Chrome DevTools Protocol. Navigate charts, develop and debug Pine scripts, inspect indicators, manage alerts, and capture chart state through structured tools.

An unofficial, independent project for chart interaction and research. It does not execute real trades.

[Explore the code](https://github.com/tradesdontlie/tradingview-mcp) · [Research notes](https://github.com/tradesdontlie/tradingview-mcp/blob/HEAD/RESEARCH.md) · [Standalone CLI](https://github.com/tradesdontlie/tradingview-cli)
